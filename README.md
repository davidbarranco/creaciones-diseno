# Creaciones & Diseño

Aplicación web de comercio electrónico para la venta
de camisetas personalizadas, mugs y productos publicitarios.

## Tecnologías

- React
- JavaScript
- Node.js
- Express
- Prisma ORM
- MySQL

## Estructura

- frontend: interfaz de usuario.
- backend: servidor y API REST.
- docs: documentación del proyecto.
